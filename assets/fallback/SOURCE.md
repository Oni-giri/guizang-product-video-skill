# CodePilot default style sources

The components and styles in this directory are extracted/adapted from CodePilot by op7418, © 2025–2026. Exact source paths and workspace content hashes are in `provenance.json`.

`CardFrame` and `CardSurface` keep the original components' "outer shadow, inner clipping" structure, with the business layout props and the Tailwind dependency removed. Buttons and badges became lightweight display components; the tokens keep the warm white / charcoal, radii and soft shadows, with type sizes and spacing adjusted for film. The headline font roles are controlled by the film's CSS variables. They are adapted components, not verbatim copies of the original repository files.
